Сервер MCP - Ограничения вызовов

Служебный регистр хранит счетчики обращений MCP по вызывающему и минуте для ограничения частоты запросов.

Как пользоваться

При отказе по частоте сократите поток обращений и проверьте клиент. Учитывайте как успешные запросы, так и неверные попытки допуска.

Что учитывать

Не сбрасывайте счетчики вручную для обхода ограничения. Заявленные клиентом имя и адрес не заменяют проверенную учетную запись.
