Тест API Генератора Диаграмм

Служебная форма проверяет вызовы API генератора диаграмм на заданных параметрах.

Как пользоваться

Выберите проверяемый сценарий, задайте необходимые входные данные и выполните вызов. Сопоставьте результат с текстом диаграммы и доступностью выбранного источника отображения.

Что учитывать

Проверочный вызов может обращаться к модели или внешнему сервису и расходовать их лимит. Используйте безопасный пример без закрытых данных. Успех отдельного вызова не заменяет проверку пользовательской формы.
