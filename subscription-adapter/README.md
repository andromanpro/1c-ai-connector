# Личные подключения ИИконы

Адаптер для Windows, проверенный с Python 3.14. ChatGPT использует официальный Sign in with ChatGPT; GLM использует изолированный профиль поддерживаемого клиента.

[Подготовка, вход и настройка модели в 1С](https://github.com/andromanpro/1c-ai-connector-guide/blob/v1.8.4/настройка-моделей/подписочные-подключения.md).

Учетные данные и код сопряжения создаются в отдельном личном каталоге. Не храните их в этом репозитории.

Локальные контрактные проверки: `py -3.14 -m unittest -v test_adapter`.
