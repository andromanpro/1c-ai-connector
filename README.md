# ИИкона — AI-коннектор для 1С:Предприятие

Расширение для работы с языковыми моделями прямо из 1С. Чат с экспертами,
инструменты для обращения к данным базы, поиск по знаниям, мониторинг ошибок
с ИИ-анализом и генерация диаграмм работают через общий коннектор.

## Что умеет ИИкона

| Возможность | Сценарий |
| --- | --- |
| Чат с экспертом | Беседы с собственной историей, моделью, черновиком и вложениями |
| Инструменты 1С | Модель уточняет метаданные и получает доступные пользователю данные выбранных баз |
| База знаний и RAG | Поиск по документам и знаниям эксперта, встроенный поиск или Qdrant |
| MCP-сервер | Внешние ИИ-агенты обращаются к инструментам 1С через HTTP |
| Мониторинг ошибок | Сбор журнала регистрации, ИИ-разбор, статистика и уведомления в Telegram |
| Диаграммы | Mermaid, PlantUML, GraphViz и BPMN по текстовому описанию |
| Контроль персональных данных | Подстановки перед внешней отправкой, настройки каналов и моделей, журнал решений |

[Подробное описание возможностей и ограничений](docs/features.md).

## Модели и подключения

Поддерживаются OpenAI-совместимые API, Anthropic, Google Gemini, YandexGPT и GigaChat.
Через совместимые API подключаются OpenRouter, DeepSeek, Mistral, Qwen и другие
провайдеры, а также локальные Ollama и LM Studio.

Для личных подписочных подключений предусмотрен [отдельный адаптер](subscription-adapter/README.md).
Доступность инструментов и вложений зависит от выбранной модели и её API.

## Установка

Текущий выпуск проверен на **1С:Предприятии 8.3.27.1989** и **БСП 3.1.11.466**.
Для облачных моделей нужен доступ к API провайдера. Qdrant, Kroki и сервис
распознавания имён подключаются для соответствующих возможностей.

1. Скачайте `.cfe` из готового выпуска.
2. Подключите его через «Администрирование → Расширения конфигурации» и обновите базу данных.
3. Откройте «ИИкона → Администрирование → Модели ИИ» и заполните предустановленные модели.
4. Настройте авторизацию нужной модели и проверьте подключение в её карточке.
5. Создайте эксперта, выберите модель и задайте системный промпт.

API-ключи хранятся в защищённом хранилище БСП. Подробный порядок установки,
настройка прав и дополнительных сервисов приведены в руководстве пользователя.

[Установка и настройка](https://github.com/andromanpro/1c-ai-connector-guide) ·
[Получение API-ключей](docs/api-keys.md) · [Обновление](docs/releases/README.md)

<a id="quick-start"></a>

## Начало работы

Откройте «Чат с экспертом», выберите эксперта и задайте вопрос.
Отправка выполняется кнопкой или сочетанием **Ctrl+Enter**.
Беседы переключаются в списке слева, панель сворачивается вбок.
Кнопка рядом с вопросом позволяет прикрепить файл.

Разработчики могут вызывать общий коннектор из своего кода.
[Примеры программных вызовов](docs/development/api-examples.md).
