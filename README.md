## 🎯 О проекте

**ИИкона (КИИ - Коннектор Искусственного Интеллекта)** — готовая библиотека для работы с языковыми моделями прямо из 1С. Единый интерфейс для всех популярных провайдеров AI.

**Инструмент для разработчиков, которым нужно добавить AI в конфигурации 1С:**

Расширение предоставляет готовый API для отправки запросов к языковым моделям. Вы можете использовать его для создания собственных решений:
- 🤖 Чат-боты для поддержки клиентов
- 📊 Автоматический анализ текстовых данных (отзывы, обращения)
- 📝 Генерация контента (описания товаров, документы)
- 🔍 Классификация и категоризация информации
- 📈 Извлечение структурированных данных из текста
- ✉️ Автоматизация ответов на запросы
- 🎯 Обогащение справочников с помощью AI

**Важно:** Расширение предоставляет только API-коннектор. Для решения конкретных задач потребуется написать свою бизнес-логику на 1С с использованием этого API.

### Зачем это нужно?

- 🔄 **Единый API** — один код работает с любой моделью
- 🚀 **Быстрая интеграция** — добавьте AI в конфигурацию за 15 минут
- 📊 **Логирование** — все запросы сохраняются для анализа
- 💰 **Контроль затрат** — отслеживайте токены и стоимость
- 🛡️ **Обработка ошибок** — готовые механизмы retry

## 📦 Установка

### Требования

- **1С:Предприятие 8.3.24+** (разрабатывалось на 8.3.27.1936)
- **БСП (Библиотека стандартных подсистем) 3.1.10.492+**
  - Тестировалось на демо базе БСП 3.1.11.392
  - Скорее всего будет работать и на более ранних версиях БСП
- Доступ в интернет для работы с API провайдеров (кроме локальных моделей)

### Протестировано на:

- ✅ **БСП Демонстрационная конфигурация 3.1.11.392**
- ✅ **1С:ERP Управление предприятием 2 (2.5.17.219)**

### Шаги установки

1. **Скачайте последний релиз**
   - [Releases](https://github.com/andromanpro/1c-ai-connector/releases)
   - Файл расширения: `IIkona_ConnectorAI_v1.0.1.cfe`

2. **Установите расширение**

3. **Обновите базу данных**

4. **Заполните предустановленные модели**
   - Откройте справочник `Модели ИИ`
   - Нажмите кнопку **"Заполнить модели"** (появляется при первом открытии)
   - Будут загружены 25+ готовых моделей

5. **Настройте API ключи**
   - Для каждой нужной модели укажите API ключ
   - **Исключение**: локальные модели (Ollama) не требуют API ключей
   - Ключи хранятся в защищённом хранилище 1С
   - После записи элемента справочника с ключом есть возможность проверить соединение - отправка тестового промпта
  
6. **Создайте Эксперта ИИ**
   - Откройте справочник `Эксперты ИИ`
   - Добавьте нового эксперта
   - Укажите настроеную модель ИИ
   - Заполните Описание эксперта - это системный промпт

## 🚀 Быстрый старт

### Тестирование без настройки

Для быстрого тестирования используйте обработку **`Тест ИИ`**:

```
Коннектор ИИ → ТестИИ → Открыть
```

В обработке можно:
- Проверить подключение к моделям
- Отправить тестовые запросы
- Посмотреть примеры работы с API
- Проверить логирование

### Простейший запрос (3 строки кода)

```bsl
Модель = Справочники.КИИ_МоделиИИ.НайтиПоНаименованию("gpt-4");
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, "Привет! Как дела?");

Если Не Ответ.ЭтоОшибка Тогда
    ОбщегоНазначения.СообщитьПользователю(Ответ.ТекстОтвета);
КонецЕсли;
```

### С системным промптом

```bsl
Промпт = Новый Структура;
Промпт.Вставить("СистемныйПромпт", "Ты — помощник программиста 1С");
Промпт.Вставить("ПользовательскийПромпт", "Как создать новый документ?");

Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, Промпт);
```

### Асинхронный запрос (фоновое задание)

```bsl
// Запускаем в фоне
ДлительнаяОперация = КИИ_КоннекторИИ.ЗапросКМоделиВФоне(Модель, Промпт);

// Ждём завершения
ДлительныеОперации.ОжидатьЗавершение(ДлительнаяОперация);

// Получаем результат

```

### Парсинг ответа в HTML

### 5. ИИ‑поздравлятор: персональные поздравления сотрудников

**ИИПоздравлятор** — пример реального использования ИИконы для автоматической генерации персональных поздравлений с днём рождения сотрудников прямо из 1С.
Подробное описание решения и кейса внедрения:  
[ИИкона в деле: ИИПоздравлятор — персонализированные поздравления сотрудников](https://infostart.ru/1c/tools/2620591/).

**Что делает решение:**

- Ежедневно находит именинников по кадровым данным и формирует список получателей.
- Генерирует индивидуальные поздравления с учётом должности, стажа и нужного стиля (официальный, дружеский, торжественный).
- Отправляет поздравления по email и/или в мессенджеры в полностью автоматическом режиме через регламентное задание.

**Как используется ИИкона:**

- 1С собирает профиль сотрудника (ФИО, должность, подразделение, стаж, формат обращения) и передаёт его в модель как структурированный промпт через коннектор. 
- Логика генерации и пересоздания поздравления (если текст не подходит) строится на базе экспертов ИИ и журналов запросов из расширения.
- Персональные данные защищены: в промпт уходит обезличенная информация, а реальные ФИО подставляются уже на стороне 1С при формировании итогового письма.

## 📖 Документация API

### Функция: ЗапросКМодели()

Выполняет синхронный запрос к модели ИИ.

#### Параметры:

**Модель** — `СправочникСсылка.КИИ_МоделиИИ`
- Модель для запроса (GPT-4, Claude, Gemini и т.д.)

**Промпт** — `Строка` или `Структура`
- **Строка**: простой текст запроса
- **Структура**:
  - `СистемныйПромпт` (Строка) — системное сообщение, определяет поведение модели
  - `ПользовательскийПромпт` (Строка) — запрос пользователя
  - `ИсторияСообщений` (Массив, необязательно) — предыдущие сообщения для контекста

#### Возвращаемое значение: Структура

```bsl
Структура:
  • ЭтоОшибка (Булево) — признак ошибки
  • ТекстОшибки (Строка) — описание ошибки
  • ТекстОтвета (Строка) — ответ от модели
  • ВходныеТокены (Число) — токенов в запросе
  • ВыходныеТокены (Число) — токенов в ответе
  • ВсегоТокенов (Число) — общее количество
  • ВремяОтветаСекунд (Число) — время выполнения
  • Модель (СправочникСсылка) — использованная модель
  • МодельОтвета (Строка) — имя модели от провайдера
  • ДатаЗапроса (Дата) — время запроса
  • ПричинаЗавершения (Строка) — stop, length и т.д.
  • IDЗапроса (Строка) — ID от провайдера
```

#### Пример:

```bsl
Модель = Справочники.КИИ_МоделиИИ.НайтиПоНаименованию("gpt-4");
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, "Привет!");

Если Не Ответ.ЭтоОшибка Тогда
    ОбщегоНазначения.СообщитьПользователю(Ответ.ТекстОтвета);
    ОбщегоНазначения.СообщитьПользователю("Токенов: " + Ответ.ВсегоТокенов);
КонецЕсли;
```

### Функция: ЗапросКМоделиВФоне()

Выполняет асинхронный запрос через длительные операции.

#### Параметры:

Те же, что у `ЗапросКМодели()`

#### Возвращаемое значение:

См. `ДлительныеОперации.ВыполнитьВФоне()`

#### Пример:

```bsl
ДлительнаяОперация = КИИ_КоннекторИИ.ЗапросКМоделиВФоне(Модель, Промпт);
ДлительныеОперации.ОжидатьЗавершение(ДлительнаяОперация);
Ответ = ПолучитьИзВременногоХранилища(ДлительнаяОперация.АдресРезультата);
```

---

### Функция: ПараметрыМодели()

Возвращает параметры модели для выполнения HTTP-запроса.

#### Параметры:

**Модель** — `СправочникСсылка.КИИ_МоделиИИ`

#### Возвращаемое значение: Структура

```bsl
Структура:
  • Адрес (Строка) — адрес API (api.openai.com)
  • АдресЗапроса (Строка) — endpoint (/v1/chat/completions)
  • ИспользоватьЗащищенноеСоединение (Булево) — HTTPS
  • ТипФорматаAPI (Перечисление) — формат API
  • НаименованиеПолное (Строка) — имя модели для API
  • Температура (Число) — параметр генерации (0.0-2.0)
  • МаксимумТокенов (Число) — лимит токенов ответа
  • Таймаут (Число) — таймаут запроса в секундах
```

## 🔑 Получение API ключей

### OpenAI
1. Зарегистрируйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдите в [API keys](https://platform.openai.com/api-keys)
3. Создайте новый ключ
4. **Важно**: пополните баланс для использования

### Anthropic (Claude)
1. Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com)
2. Перейдите в [API Keys](https://console.anthropic.com/settings/keys)
3. Создайте новый ключ

### Google (Gemini)
1. Зарегистрируйтесь в [Google AI Studio](https://aistudio.google.com)
2. Нажмите "Get API key"
3. Создайте ключ для вашего проекта

### DeepSeek
1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com)
2. Перейдите в API Keys
3. Создайте новый ключ

### GigaChat (Сбер)
1. Зарегистрируйтесь на [developers.sber.ru/gigachat](https://developers.sber.ru/gigachat)
2. Получите ClientId и ClientSecret
3. В 1С укажите в формате: `Authorization key` ИЛИ `ClientId:ClientSecret`
4. Модуль автоматически обменяет на OAuth2 токен

### Yandex GPT
1. Зарегистрируйтесь в [Yandex Cloud](https://console.cloud.yandex.ru)
2. Создайте сервисный аккаунт
3. Получите API-ключ
4. В модели укажите ваш Folder ID

### Требуется ли БСП?

Да, требуется **БСП (Библиотека стандартных подсистем) 3.1.10.492 или выше**.  
Тестировалось на БСП 3.1.11.392, но должно работать и на более ранних версиях БСП 3.1.x.

### На каких конфигурациях работает?

Протестировано на:
- ✅ БСП Демонстрационная конфигурация 3.1.11.392
- ✅ 1С:ERP Управление предприятием 2 (2.5.17.219)

Должно работать на любой конфигурации с БСП 3.1.10.492+.

### Как протестировать расширение?

Используйте обработку **`КИИ_ТестИИ`** для быстрой проверки:
```
Обработки → КИИ_ТестИИ → Открыть
```

### Нужны ли API ключи для всех моделей?

Нет. API ключи нужны только для облачных провайдеров (OpenAI, Claude, GigaChat и т.д.).  
**Локальные модели через Ollama** работают без API ключей.

### Где хранятся API ключи?

В защищённом хранилище 1С (`ОбщегоНазначения.ХранилищеОбщихНастроек`). Ключи зашифрованы и не попадают в выгрузки.

### Можно ли использовать без интернета?

Да, с локальными моделями через **Ollama**. Они не требуют API ключей и работают полностью офлайн.  
Остальные провайдеры требуют подключения к интернету.

### Как контролировать затраты?

Все запросы логируются в регистр сведений с информацией о токенах. Можно создать отчёт по расходу токенов и стоимости.

### Работает ли на Linux?

Да, 1С:Предприятие на Linux поддерживается. Расширение кроссплатформенное.

### Можно ли использовать в коммерческих проектах?

Да, лицензия MIT позволяет свободное коммерческое использование.

### Поддерживается ли отправка изображений?

В текущей версии (v1.0.0) — нет. Поддерживаются только текстовые запросы.  
Vision API планируется в версии 1.2.0.

### Можно ли добавить свои провайдеры?

Да! Любой провайдер с **OpenAI-compatible API** работает из коробки:

**Уже поддерживаются (требуется только настройка модели):**
- OpenRouter (доступ к 100+ моделям)
- Together.ai
- Fireworks.ai
- Anyscale
- Replicate
- Hugging Face Inference API

**Как добавить:**
1. Создайте новый элемент в справочнике `КИИ_МоделиИИ`
2. Укажите адрес провайдера
3. Выберите формат API: `OpenAI_Compatible`
4. Укажите имя модели и API ключ
5. Готово!
