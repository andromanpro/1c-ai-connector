## Интерфейс 1.6.2

В разделе «ИИкона» команды сгруппированы по работе:

| Группа | Что открыть |
|---|---|
| Работа с ИИ | чат с экспертом, эксперты, генератор диаграмм |
| Знания | база знаний, категории и фрагменты |
| Мониторинг | ошибки, статистика, дашборд и журналы |
| Администрирование | модели, мониторинг, MCP и контроль персональных данных |

Поиск можно проверить из карточки знания, ее списка или карточки эксперта:

форма показывает найденные источники и их полный текст. Это проверка поиска;

чат-модель для генерации ответа не вызывается. Внешний эмбеддер получает вопрос

после подтверждения. Подробнее — в [руководстве](https://github.com/andromanpro/1c-ai-connector-guide/tree/main/rag).
