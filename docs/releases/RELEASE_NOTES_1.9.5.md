# ИИкона 1.9.5

- Исправлена отправка вопроса с базовыми правами. При проверке контекста беседы системные настройки контроля персональных данных читаются отдельно. [Issue №3](https://github.com/andromanpro/1c-ai-connector/issues/3)
- Сохранение карточки модели записывает или удаляет API-ключ после изменения поля ключа. Сбой чтения больше не приводит к удалению сохранённого ключа при записи других полей.
- Готовый BPMN с корнем `bpmn:definitions` распознаётся как диаграмма.
- В Gemini служебные части `thought` исключены из отображаемого текста. Оригинальные части и подписи сохраняются для продолжения инструментального раунда.
- При разборе ответов Google и Yandex соответствующий узел извлекается один раз. Сервер MCP использует один реестр на вызов инструмента.
- Убраны избыточные объявления и повторные вычисления. Результаты запросов, вызовов и промежуточных вычислений имеют собственные имена. Сложные условия разнесены по явным ветвям.

## Связанные компоненты

- Таймаут MCP-прокси охватывает заголовки и тело ответа. Обрыв при чтении тела возвращается как сетевая ошибка. [Коммит MCP-прокси](https://github.com/andromanpro/1c-ai-connector-mcp-proxy/commit/9014f7a5dc130f4e2181d8355aea9828b1fea1e0)
- Мост аудитора завершает открытый сеанс при ошибке исполнения запроса. [Коммит моста аудитора](https://github.com/andromanpro/1c-ai-connector-audit-shim/commit/e6c17098bd6b77970374cb3665c1301db0a9d004)

## Установка

Обновите расширение ИИконы файлом `IIkona-1.9.5.cfe`. Для регрессионного стенда доступен отдельный файл `IIkona-tests-1.9.5.cfe`. Полный архив включает руководство и подписочный адаптер.
