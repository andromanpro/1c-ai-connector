# ИИкона 1.9.7

Предпросмотр персональных данных сохраняет документные метки «Редакция А.», «Вариант Б.», «Версия В.», «Приложение Г.», «Раздел Д.» и «Пункт Е.». Раньше ИИкона могла принять такую метку за фамилию с инициалом и заменить её в тексте. Фамилии с инициалами по-прежнему распознаются, в том числе рядом с документной меткой.
