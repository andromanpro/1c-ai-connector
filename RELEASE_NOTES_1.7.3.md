# ИИкона 1.7.3

В чате с экспертом появился флажок «Использовать инструменты». Эксперт может уточнить устройство текущей базы и получить доступные пользователю данные, прежде чем дать ответ.

## Как пользоваться

1. В карточке модели эксперта включите «Поддерживает инструменты (function-calling)», если выбранная модель и её API поддерживают вызов функций.
2. Откройте «Чат с экспертом» и включите «Использовать инструменты».
3. Задайте вопрос о текущей базе. Модель сама выбирает нужные инструменты и продолжает ответ по их результатам.

Флажок первоначально выключен и сохраняется в настройках формы. Доступны четыре встроенных инструмента: дерево метаданных, структура объекта, сведения о конфигурации и запрос данных на чтение в пределах прав пользователя. Дополнительный сервер для этих инструментов не нужен.

В этом режиме сохраняются история беседы, вложения и знания эксперта. Токены и стоимость учитываются по всем раундам, включая завершающий ответ при достижении лимита. Контроль персональных данных действует на протяжении всего диалога; исходные значения восстанавливаются в ответе для человека.

## Обновление

Обновите существующее расширение обычным способом и перезапустите сеанс. Пользователи, модели и настройки сохраняются. Повторный перенос данных и пересборка индексов знаний при переходе с 1.7.2 не требуются.

Прежние публичные вызовы совместимы. Для разработчика добавлены метод `ЗапросКМоделиСИнструментами` и необязательный четвёртый параметр `ИспользоватьИнструменты` у `ЗапросКМоделиВФоне`.

Отдельный список инструментов для каждой модели и внешние MCP-подключения включены в план развития. Вкладка журнала «Вопрос и контекст» пока показывает сохранённый контекст беседы, а не полное HTTP-тело с блоком `tools`.
