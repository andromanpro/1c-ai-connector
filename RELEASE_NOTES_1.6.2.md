# ИИкона 1.6.2

В этой версии упорядочен интерфейс и добавлена проверка поиска по базе знаний. Исправлены замечания статического анализа; действующие публичные методы поиска сохранены для совместимости.

## Что нового

- Раздел «ИИкона» состоит из четырех групп: «Работа с ИИ», «Знания», «Мониторинг», «Администрирование». База знаний, категории и фрагменты доступны прямо из меню.
- В карточке и списке знаний видны состояние индекса, число фрагментов, готовность к поиску, даты текста и индекса. Единая форма проверки открывается из базы знаний, ее списка и карточки эксперта. Показывает найденные источники, сходство и полный текст; позволяет открыть источник и скопировать фрагмент.
- В списке моделей оставлены основные сведения. Карточка разделяет подключение и авторизацию, показывает итоговый адрес. Проверка выполняет новый запрос по записанным настройкам и выводит время, адрес, ответ или ошибку. Для эмбеддингов проверяется пригодность вектора, включая размерность.
- «Тест ИИ» переименован в «Чат с экспертом». Новый диалог требует подтверждения. У вложений показаны размер и состояние отправки; доступны просмотр, сохранение и удаление исходящих файлов.
- В генераторе диаграмм разделены описание, код и подключение. Построение запускается отдельной командой; доступны сохранение SVG, PNG и PDF.
- В мониторинге уведомления Telegram отключаются отдельным флажком. В журналах можно прочитать исходную ошибку и разбор, скопировать результат, открыть связанные запросы. Правило игнорирования проверяется до записи.
- Настройки персональных данных отделены от пробной проверки. Базовая роль не получает ключи моделей и команды изменения индекса из карточки.

## Исправлено

- Устранены лишние контекстные серверные вызовы при выделении ошибки, повторяющиеся обработчики форм, сложные участки RAG, ядра и авторизации MCP.
- Исправлены проверка подключения, обработка пустого ответа и неверного вектора. Отмена ожидания позволяет вернуть управление форме; повтор блокируется, пока прежняя операция выполняется. Прерывание удаленного HTTP-запроса не гарантируется.
- Восстановление прежнего привилегированного режима при работе с ключом выполняется до обработки ошибки.

## Обновление

Установите `IIkona_ConnectorAI_v1.6.2.cfe` поверх прежнего расширения и перезапустите сеансы. Обновление с 1.6.1 проверено на отдельной копии базы: модели, эксперты и настройки сохраняются, прежний вызов API работает, регламенты очистки не дублируются. Изменения данных вручную для перехода с 1.6.1 не требуются.

Для более старых версий соблюдайте инструкции соответствующих обновлений в README. Предустановки обновляются командой «Обновить предустановленные модели»; ключи сохраняются. Свои модели с другими названиями не перезаписываются.

## Проверено

- 19 проверок установки и обновления собранного файла: все успешны. Содержимое установленного пакета сверено с исходниками EDT: 81 модуль, метаданные, формы и права.
- Контрольный набор YAxUnit: 461 тест, 455 успешно, 0 ошибок, 6 пропусков. Пять требуют отсутствующего локального сервиса распознавания имен; один сценарий отсутствующих реквизитов MCP неприменим при уже заполненных реквизитах. Полный набор с живыми обращениями к провайдерам в эту проверку не входил.
- SonarQube: Quality Gate пройден, активных замечаний нет, новые повторения 0%; все 28 точек проверки безопасности рассмотрены. 203 исходных замечания исправлены кодом. Еще восемь решений рассмотрены отдельно: четыре ложных срабатывания и четыре сохраненных случая (три публичные сигнатуры RAG ради совместимости, предупреждение о недоступном необязательном NER). Правила профиля не отключались.
- Интерфейс: тонкий клиент, роли администратора и базовая роль, окна 1024×768 и 1280×800, масштаб системы 150%. Проверены поиск знаний, подключения к локальному проверочному серверу, отмена ожидания, вложения, сохранение диаграмм и журналы.

Веб-клиент, серверная база, другие масштабы и живые интеграции с Qdrant и NER требуют отдельной приемки. Responses API и совместимый переход публичных методов RAG на структуру параметров остаются будущими работами.
