# ИИкона 1.7.4

В журнале запросов теперь сохраняется контекст работы эксперта с инструментами.
Раньше ответ, расход токенов и отдельные раунды записывались, а поля вопроса,
инструкции и контекста могли оставаться пустыми.

## Что изменилось

- На вкладке «Вопрос и контекст» заполняются вопрос и системные инструкции.
- Для инструментальных запросов сохраняются сообщения, вызовы и результаты
  инструментов и предложенный модели каталог функций: JSON с `messages` и `tools`.
- Содержимое записывается после контроля персональных данных, в том числе у раунда,
  завершившегося ошибкой модели. Заголовки HTTP и ключ авторизации модели не добавляются.
- Обычные запросы без инструментов сохраняют прежний формат истории.

Для работы с инструментами по-прежнему включите поддержку function-calling в модели
и флажок «Использовать инструменты» в чате эксперта.

## Обновление

Обновите существующее расширение обычным способом и перезапустите сеанс 1С.
Данные, пользователи, модели и настройки сохраняются. Повторный перенос данных
и пересборка индексов базы знаний для этого обновления не нужны.

Публичные вызовы коннектора совместимы с 1.7.3. Формат контекста обычного запроса
не меняется; инструментальный контекст теперь содержит объект с `messages` и `tools`.
